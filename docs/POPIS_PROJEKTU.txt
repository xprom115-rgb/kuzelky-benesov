POPIS PROJEKTU: soubory a bloky
=============================

A) Stránky (HTML)
- index.html
  - úvod + dlaždice Zápasy
  - načítá index-matches.js

- rezervace.html
  - datum #date, sloty #lanes, modál #res-form (form #reservation-form)
  - načítá rezervace.js (logika rezervací)
  - načítá rezervace-events-block.js (blokace slotů podle events)

- aktuality.html
  - výpis aktualit
  - (doplněno) výpis events (skutečný čas start–end)

- druzstvo-a/b/c.html
  - tabulka (z JSON přes team-page.js)
  - budoucí zápasy (abc-future.js)
  - minulé zápasy (abc-past.js)

- historie-muzstev.html
  - dlaždice týmů A/B/C/Dorost → historie-tym.html?team=...

- historie-tym.html + historie-tym.js
  - výpis sezón z team_history/{team}/seasons
  - detail sezóny:
    - A/B/C: finalTable + pastList
    - DOROST: summaryBulletin (souhrn 8. kola)

B) Admin (HTML)
- admin.html
  - rozcestník dlaždic

- admin-rezervace.html + admin-rezervace-admin.js
  - login (Firebase Auth)
  - realtime seznam rezervací + mazání + úklid do včerejška

- admin-druzstva.html + admin-druzstva.js
  - DOROST: team_manual/DOROST (bulletins 1–8), historie jen 8. kolo
  - A/B/C: team_current/{A|B|C} (seasonId, teams[], future{}, past{})
  - archivace: team_history/{A|B|C}/seasons/{season} (finalTable + pastList)

- admin-akce.html + admin-akce.js
  - zadávání events (zápasy/turnaje)
  - ukládá skutečný čas start/end + blokaci blockStart/blockEnd (na hodiny)

C) Firestore kolekce
- reservations
  - rezervace drah

- events
  - zápasy/turnaje pro blokaci rezervací + výpis do aktualit

- team_current/{A|B|C}
  - živá sezóna: teams[], future{}, past{}

- team_manual/DOROST
  - dorost zpravodaje (URL)

- team_history/{team}/seasons/{season}
  - historie (snapshot)
  - A/B/C: finalTable + pastList
  - DOROST: summaryBulletin
